# تذكير 🌙

تطبيق ويب يومي للأذكار والأدعية والاستغفار، وتذكير المستخدم بأوقات العبادة — مبني بـ React 18 + Vite + Tailwind CSS، بواجهة عربية كاملة (RTL) وتصميم مستوحى من الأجواء الروحانية والفن الإسلامي الهندسي البسيط.

## الميزات

- **الأذكار**: 11 فئة (الصباح، المساء، النوم، الاستيقاظ، السفر، الطعام، المنزل، الشفاء، الهم والكرب، الجمعة، طلب العلم)، مع عدّاد تكرار لكل ذكر وشريط تقدم عام، يُحفظ يوميًا في المتصفح.
- **السبحة**: عداد تفاعلي كبير بالضغط، اختيار الذكر (استغفار / تسبيح / تحميد / تكبير / تهليل)، هدف قابل للتخصيص (33 / 100 / رقم حر)، وإحصائية يومية وأسبوعية.
- **دعاء اليوم**: دعاء يتغيّر تلقائيًا كل يوم، مع نسخ وتصفّح يدوي بين الأدعية.
- **الصلاة والقبلة**: أوقات الصلاة الخمس الحقيقية (حسب موقع المستخدم عبر خدمة Aladhan، طريقة أم القرى) مع تمييز الصلاة القادمة، وبوصلة اتجاه القبلة (زاوية ثابتة محسوبة، مع خيار تفعيل بوصلة الجهاز الحيّة).
- **تقدّمي**: متتالية التزام يومية (Streak) بشارات عند بلوغ 3/7/14/30/60/100/365 يومًا، تُحتسب تلقائيًا عند إتمام أي فئة أذكار أو هدف سبحة أو ورد قرآني؛ وختمة قرآن كاملة مع تتبّع الورد اليومي (صفحات)، هدف يومي قابل للتخصيص، ورسم بياني لآخر 7 أيام.
- **التذكيرات**: تذكيرات افتراضية لأذكار الصباح/المساء وأوقات الصلاة (قابلة لتعديل الوقت يدويًا، أو مزامنتها تلقائيًا مع الأوقات الحقيقية بضغطة زر)، بالإضافة إلى تذكيرات خاصة يضيفها المستخدم، تظهر كتنبيه داخل الصفحة وكإشعار متصفح (Notification API) عند تفعيله.
- **عدّاد الزوار**: عدّاد إجمالي لعدد زيارات الموقع يظهر أسفل الصفحة (راجع قسم "عدّاد الزوار" أدناه لتفعيل النسخة الحقيقية المشتركة بين كل الزوار).
- **وضع ليلي/نهاري تلقائي** حسب إعدادات نظام المستخدم.
- خطوط عربية من Google Fonts: **Amiri** للعناوين، **Tajawal** للنصوص.

## التشغيل محليًا

يتطلب Node.js 18 أو أحدث.

```bash
npm install
npm run dev
```

سيعمل التطبيق على `http://localhost:5173`.

للحصول على نسخة إنتاجية محليًا:

```bash
npm run build
npm run preview
```

## النشر على Vercel

المشروع جاهز للنشر مباشرة بدون أي إعدادات إضافية:

```bash
npm install -g vercel   # إن لم تكن مثبّتة لديك
vercel deploy
```

أو ببساطة اربط المستودع من لوحة تحكم Vercel واختر "Import Project" — سيكتشف Vercel أنه مشروع Vite تلقائيًا (أمر البناء `vite build`، مجلد الإخراج `dist`) وسينشر أيضًا دالة `api/visits.js` كدالة Serverless تلقائيًا.

## عدّاد الزوار (الميزة المشتركة بين كل الزوار)

عدّاد الزوار يعمل مباشرة بعد النشر **بدون أي إعداد إضافي**، لكنه في هذه الحالة عدّاد محلي تقريبي (يُحسب لكل جهاز/متصفح على حدة عبر `localStorage`) لأن دالة `api/visits.js` لا تجد قاعدة بيانات مشتركة فتعيد `live: false`، فيتحول الواجهة تلقائيًا للعدّاد المحلي.

لتفعيل عدّاد **حقيقي مشترك بين كل زوار الموقع** (يستغرق دقيقتين):

1. من لوحة تحكم مشروعك على Vercel: **Storage → Marketplace Database Providers → Upstash → Redis → Connect** (أو أي تكامل Redis آخر متوافق).
2. سيضيف Vercel تلقائيًا متغيّرَي البيئة `UPSTASH_REDIS_REST_URL` و `UPSTASH_REDIS_REST_TOKEN` لمشروعك.
3. أعد النشر (Redeploy) — ستبدأ دالة `api/visits.js` تلقائيًا باستخدام القاعدة الحقيقية وإرجاع `live: true`، وسيتحول العدّاد فورًا إلى عدّاد مشترك حقيقي بين كل الزوار.

لا حاجة لتعديل أي كود؛ الدالة مكتوبة لتكتشف وجود القاعدة تلقائيًا.
